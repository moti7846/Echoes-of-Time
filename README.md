# Echoes of Time – פרויקט היסטוריה ב-HTML

## 🏛 נושא הפרויקט: בית המקדש

הפרויקט נבנה כחלק ממשימה בלימודי היסטוריה וטכנולוגיה, בה נתבקשנו לבנות אתר בן 4 דפים המתאר תקופה היסטורית — ללא שימוש ב-CSS, JavaScript או טפסים.  
האתר עוסק בבית המקדש, וכולל מידע היסטורי בסיסי בארבעה דפי תוכן.

---

## 📄 מבנה האתר

### 1. `index.html` – דף הבית
- פתיח כללי על בית המקדש
- מידע בסיסי על משמעותו וחשיבותו
- ניווט לדפים הנוספים

### 2. `origins.html` – מקורות ובניית המקדש
- מידע על בניית המקדש הראשון והשני
- התפקידים של שלמה המלך והעולים מבבל

### 3. `destruction.html` – חורבן בית המקדש
- מידע על חורבן הבית הראשון והשני
- מקורות מקראיים והיסטוריים

### 4. `memory.html` – זכר לבית המקדש
- איך זוכרים את בית המקדש עד היום?
- טקסים, מנהגים, ויום תשעה באב
- מחשבות לעתיד
